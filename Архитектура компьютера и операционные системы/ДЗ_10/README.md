# Отчёт по домашней работе №10
Яровицына Наталья | БПИ244

## Описание
Программа реализует многопоточную систему обработки данных, где 100 параллельных источников генерируют числа, которые суммируются в общем буфере.

## Особенности реализации

### Архитектура
- **3 типа потоков**: источники, сумматоры, контроллер
- **Общий буфер**: статический массив на 200 элементов (с удалением элементов через сдвиг массива)
- **Синхронизация**: мьютексы + условные переменные
- **Фиксация событий**: протокол всех операций

### Ключевые компоненты
1. source_thread() - 100 потоков-источников
2. controller_thread() - поток-контроллер
3. sum_thread() - потоки-сумматоры
4. protocol - структура для протокола
5. add_protocol() - функция добавления записей в протокол

## Выполненные требования

### Основные требования
- [x] 100 параллельных источников чисел (1-100)
- [x] Общий буфер на 200 элементов — хранит числа и результаты
- [x] Контроллер — быстро отслеживает данные, при появлении пары чисел сразу запускает сумматор
- [x] Потоки-сумматоры — работают 3-6 сек, возвращают сумму обратно в буфер
- [x] Параллельность — несколько сумматоров могут работать одновременно
- [x] Случайные пары — контроллер берёт любые два числа из буфера
- [x] Автозавершение — программа останавливается, когда остаётся один итоговый результат
- [x] Подробный протокол — все события записываются с временными метками
- [x] Безопасность потоков — мьютексы и условные переменные защищают общие данные

### Дополнительные требования
- [x] Обработка переполнения буфера — потоки ждут при buffer_count >= BUFFER_SIZE
- [x] Обработка опустошения буфера — контроллер ждет при buffer_count < 2
- [x] Безопасное завершение — использование флага is_finish для корректного завершения всех потоков
- [x] Динамическое управление памятью — освобождение всех выделенных ресурсов
- [x] Проверка корректности завершения — вывод состояния системы в конце работы
