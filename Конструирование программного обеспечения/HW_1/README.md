Система учета Московского зоопарка

Проект представляет собой консольное приложение для управления животными и инвентарем зоопарка.

Функциональность

Управление животными
- Добавление новых животных
- Просмотр всех животных зоопарка
- Фильтрация животных для контактного зоопарка
- Расчет потребности в еде для всех животных
- Автоматическая нумерация животных

Управление инвентарем
- Добавление новых вещей в инвентарь
- Просмотр всего инвентаря зоопарка
- Автоматическая нумерация вещей

Дополнительные возможности
- Ветеринарный осмотр животных
- Интерактивная проверка здоровья с поддержкой русского и английского языков

Ключевые интерфейсы
- IAlive - маркерный интерфейс для живых существ
- IInventory - интерфейс для объектов инвентаря
- IHerbivorous - интерфейс для травоядных животных
- IZooService - сервис для работы с зоопарком
- IZooRepository - репозиторий для хранения данных
- IVeterinaryClinic - ветеринарная служба

Модели животных

Базовые классы
- Animal - абстрактный базовый класс всех животных
- Herbivorous - абстрактный класс травоядных животных
- Predator - абстрактный класс хищных животных

Конкретные реализации
- Monkey (Обезьяна) - травоядное, может быть в контактном зоопарке
- Rabbit (Кролик) - травоядное, может быть в контактном зоопарке
- Tiger (Тигр) - хищник, не может быть в контактном зоопарке
- Wolf (Волк) - хищник, не может быть в контактном зоопарке

Модели вещей

Базовый класс
- Thing - абстрактный базовый класс всех вещей

Конкретные реализации
- Table (Стол) - конкретная реализация вещи
- Computer (Компьютер) - конкретная реализация вещи

Особенности

Для контактного зоопарка
Животное может находиться в контактном зоопарке если:
- Является травоядным (IHerbivore)
- Уровень доброты > 5 (KindnessLevel > 5)

Медосмотр
Каждое животное проходит обязательную проверку здоровья перед добавлением в зоопарк.

Автоматическая нумерация
- Животные получают последовательные номера начиная с 1
- Вещи получают последовательные номера начиная с 1

Тестирование проекта

Обзор тестирования

Проект включает комплексные unit-тесты, обеспечивающие более 80% покрытия кода. Тесты проверяют все основные компоненты системы и соответствуют принципам SOLID.

Структура тестов

Основные тестовые категории:
1. Тесты ZooService
- AddAnimal_HealthyAnimal_ReturnsTrue() - добавление здоровых животных
- AddThing_ShouldAddThingToRepository() - добавление вещей в инвентарь
- PrintMethods_ShouldNotThrowExceptions() - стабильность методов вывода

2. Тесты ZooRepository
- GetAnimalsForContact_ShouldReturnKindAnimals - фильтрация животных для контактного зоопарка
- GetTotalFoodRequired_ShouldReturnCorrectSum - расчет общей потребности в еде
- GetAllAnimals_ShouldReturnAllAddedAnimals - получение всех животных
- GetAllThings_ShouldReturnAllAddedThings - получение всех вещей
- Animals_ShouldGetAutoIncrementedNumbers - автоматическая нумерация животных
- Things_ShouldGetAutoIncrementedNumbers - автоматическая нумерация вещей

3. Тесты VeterinaryClinic
- CheckHealth_ShouldSetHealthAnimals() - проверка здоровья животных

4. Тесты интерфейсов и моделей
- Animal_ImplementsInterfaces_Correctly - проверка реализации интерфейсов
- Monkey_ShouldImplementCorrectInterfaces - интерфейсы обезьяны
- Tiger_ShouldImplementCorrectInterfaces - интерфейсы тигра
- Wolf_ShouldImplementCorrectInterfaces - интерфейсы волка
- Herbivore_CanBeInContactZoo_WhenKindnessAbove - логика контактного зоопарка
- Thing_ImplementsInventoryInterface - интерфейсы вещей
- Thing_GetInventoryInfo_ReturnsCorrectInfo - информация об инвентаре вещей
- Animal_GetInventoryInfo_ReturnsCorrectInfo - информация об инвентаре животных

Инструкция по запуску проекта MoscowZoo

Предварительные требования
- .NET 8.0 SDK или новее
- Поддерживаемые ОС: Windows 10+, macOS 10.15+, Linux

Пошаговая инструкция
1. Запуск unit-тестов (рекомендуется сначала)
```bash
# Переходим в папку с тестами
cd Test

# Запускаем все тесты
dotnet test

# Или с подробным выводом
dotnet test --verbosity normal
```
2. Запуск основного приложения
```bash
# Возвращаемся в корневую папку проекта (если нужно)
cd ..

# Переходим в папку основного проекта
cd MoscowZoo

# Запускаем приложение
dotnet run
```

Что должно произойти:
1. При запуске тестов - вы увидите результаты проверки всех компонентов системы
2. При запуске приложения - запустится консольное приложение зоопарка с демонстрацией работы всех функций
